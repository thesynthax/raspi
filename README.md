# Raspi: Self-hosted applications on Raspberry Pi Server
## Vision:
- Creating a self-hosted system to reclaim your internet freedom
- Removing trust in third-party proprietary applications 
- Having absolute control over your data and privacy
- Developing a centralized home server that can be used for a plethora of tasks

The list of services and software self-hosted can be found at https://services.thesynthax.xyz

These services include:
- Media management services like *arr and Jellyfin (alternative to Netflix)
- Data management services like Nextcloud and Dropifi (alternative to Google Drive)
- Password management service like GNUPass (alternative to Dashlane)
- Version control service like Cgit (alternative to GitHub)
- VPN service like Wireguard (alternative to ExpressVPN)
- Search engine service like SearXNG (alternative to Google Search)
- File synchronization service like Syncthing (alternative to proprietary sync apps)

All the applications hosted are open-source and privacy-oriented.

## System Specifications
- Model Raspberry Pi 4B
- RAM: 8GB
- OS: Raspberry Pi OS
